Python Phase 4 Controlled Failure Drill
Mission: Regional Cold Chain Incident Batch Pipeline 🧊🚚⚔️

Today’s theme: cold chain supply chain monitoring.

You are working for a company that moves temperature-sensitive products across warehouses: vaccines, fresh produce, frozen seafood, insulin, and specialty foods.
Each regional warehouse sends a daily JSON file containing shipment temperature incident reports.
Your job is to build a batch pipeline that scans a raw folder, processes multiple JSON files, survives broken files, validates records, transforms valid records, writes outputs, and creates a run summary.
