## SERIES GUIDELINE

This is an umbrella folder that entails all projects and pipelines used in the learning python2 series.
One environment is created to house all the folders, packages and modules ~ .zoezi_venv.
The list of all the packages used in the environment is in requirements.txt.
However, each project or pipeline has its own project pipeline set up.
